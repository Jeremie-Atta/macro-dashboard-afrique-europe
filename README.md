# Tableau de bord macroéconomique – Afrique vs Europe

Ce projet propose une analyse macroéconomique comparative (2000–2024) basée
sur les données de la World Bank.

## Contenu
- Collecte automatisée via API officielle
- Nettoyage et structuration des données
- Analyse exploratoire et comparative
- Note d’analyse macroéconomique (PDF)
- Dashboard interactif (Streamlit – à venir)

## Indicateurs
PIB, croissance, inflation, chômage, dette publique, PIB par habitant

## Limites
Certaines séries (dette publique, chômage) présentent des valeurs manquantes,
notamment pour les pays africains.
